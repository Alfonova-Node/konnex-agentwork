# Grant MVP Scope

## Objective
Build practical infrastructure for autonomous physical-work coordination: task creation, execution, machine-readable proof, verification, reward accounting, and reputation.

## Milestones
1. Core task and agent API.
2. Simulated worker environment.
3. Proof validation and reputation.
4. SDK and dashboard.
5. Konnex testnet integration and on-chain settlement after network-specific deployment details are confirmed.

## Success metrics
- End-to-end task completion locally.
- Deterministic verification of work proofs.
- Developer SDK can create and validate tasks.
- Clear Konnex settlement integration boundary.
